## **Problem Statement**



###### Problem:-



Morse code is one of the earliest digital communication codes. Converting it by hand is slow and error-prone, and simple converters usually work in one direction only and ignore invalid input silently. Students learning programming and communication basics need a small tool that converts both ways, reports mistakes clearly and shows how the signal is timed.



###### Scope:-



* Convert text (letters, digits, spaces) to Morse code
* Convert Morse code back to text
* Show the Morse signal as a pattern of ON/OFF units using standard timing
* Validate all input and show clear error messages
* Keep a log of the session
* Runs in the terminal with basic Python 3 and no external libraries



&#x20;  Out of scope: audio output, graphical interface, punctuation and non-English characters.



###### Target Users:-

&#x20;

* First-year students learning problem solving and Python programming
* Beginners learning Morse code



###### High-Level Features:-



1. Text-to-Morse encoder
2. Morse-to-text decoder
3. Morse signal pattern with unit counts
4. Input validation and error messages
5. Session log with success and error counts
6. Test files for each module
